A page-by-page romantic surprise: cover with heart garlands, a typewriter love letter with polaroids,
three clickable heart promises, an "Our Song" player with lyrics, and an "I LOVE YOU" heart collage.

## Personalise it

Edit `bf-data.ts` — names, letter paragraphs, promise texts, lyrics, photos and stickers all live there.

```ts
export const couple = { to: 'My Love', from: 'Your Girl' };
```

## Run it

```
bit run boyfriends-day
```
